# Educational Guide

## Goal
Use visual and symbolic math workflows to explain concepts incrementally.

## Recommended flow
1. Define a function or surface in DSL.
2. Visualize it with renderer math mesh generation.
3. Show derivative/integral behavior with runtime math evaluation.
4. Introduce parameter variation and compare outcomes.

## Current status
The project currently has MVP support for:
- math expressions and lowering
- runtime derivative/integral evaluation with fallbacks
- renderer mesh generation for function and surface plots

## Next educational improvements
- step-by-step derivation output
- guided hints tied to semantic diagnostics
- interactive exercises with answer checking
